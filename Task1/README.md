# Используемые системы

- **АБС (Delphi + Oracle)** - это основная система, где производится учёт операций по счетам и бухгалтерия
- **СМС-шлюз телеком-оператора**. Его поддерживает IT-отдел банка, взаимодействуя с телеком-оператором.
- **Телеком-оператор** — внешний оператор по отправке СМС.
- **Система кол-центра (веб-интерфейс на React.js, бэкенд на Java Spring Boot + PostgreSQL)** - клиент-серверная система на платформе подрядчика. CRM подрядчика. Система развёрнута в инфраструктуре банка и полностью поддерживается подрядчиком.
- **Система партнёрского кол-центра** - это внешняя система. Партнёрский кол-центр + подрядчик, чью систему использует кол-центра банка, — разные компании.
- **Онлайн-обслуживание** через партнерский коллцентр
- **Кредитный конвейер (Camunda + Oracle)** -  cистема для обработки заявок на кредит. Систему дорабатывают частично сотрудники подрядчика, который внедрял систему, но также в IT-отделе есть специалисты, которые могут менять обработчики и описания бизнес-процессов в системе
- **Система кредитного скоринга (Python + Flask + PostgreSQ + AI)** - Источники данных — АБС и Бюро кредитных историй. Система разрабатывается сотрудниками в IT-отделе
- **Бюро кредитных историй**. Внешняя система, которая предоставляет данные через REST API.
- **Интернет-банк (ASP.NET MVC 4.5 + MS SQL)** Монолит реализован на платформе подрядчика. Есть резервный ЦОД, на который можно переключиться в случае сбоя
- **Сайт (PHP + React.js)* — разработка банка
